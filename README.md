# DevMentor AI

Assistente virtual voltada para jovens desenvolvedores.

## Objetivo

A DevMentor AI tem como objetivo auxiliar jovens programadores
no processo de aprendizagem e desenvolvimento de software.

## Funcionalidades

- Perfil do desenvolvedor
- Menu interativo
- Mensagens motivacionais
- Área de estudo
- Seleção de linguagens
- Memória do utilizador
- Assistência baseada em IA

## Tecnologias

- Python
- Git
- GitHub
- Ollama
- LLMs
